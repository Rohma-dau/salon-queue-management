# Project Reflection

During this project, I learned how to use AI-assisted vibe coding to develop a Salon Queue Management System. One issue I faced was that customer and owner navigation were not properly separated. The customer could see owner settings while navigating through the application, which created a confusing experience.

I identified this issue by manually testing the application and comparing its behaviour with the assignment requirements. I then refined my instructions to clearly explain the separate roles and navigation flows for customers and salon staff.

Another challenge was deployment. I faced dependency and Node.js version compatibility issues while deploying the application. I addressed this by configuring the Node.js version required for the project.

This experience taught me that AI-generated code still requires proper planning, documentation, testing and debugging. Clear prompts and well-defined requirements make a significant difference in the final result.
